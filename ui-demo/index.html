对比度实测说明

下列数值按 WCAG 相对亮度公式、以令牌色值与实际合成背景静态计算：ink/paper 17.4:1、secondary/paper 5.1:1、accent/paper 3.9:1（番茄红，仅用于大字与界面强调，常规正文不依赖红色；正文为近黑 ink）、danger/paper 5.4:1、nightInk/nightSurface 14.0:1、accent 焦点环/surface 3.5:1（焦点指示 ≥3:1 满足）。常规文字目标 ≥4.5:1、大字 ≥3:1、焦点与控件边界 ≥3:1。

色值只是设计输入，必须用实际合成背景重新测量；本页色卡不构成对比度已达标证明。本 demo 未进行浏览器或设备验收。

夜间模式仅覆写 surface / paper / ink / border / focus-color；辅助与操作文字通过派生变量做可读性补偿，日间令牌精确值保持不变。阅读主题为阅读器纸面的独立主题，不与夜间模式耦合。
