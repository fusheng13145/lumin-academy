## 四、视觉语言与合规边界

- **视觉语言（定稿）**：「纸页与朱印」——以番茄红 `#E8453B` 为**标记色**（下划线、圆点、当前项、主按钮），标题与书页用宋体栈、界面用系统无衬线；细线平面卡片、克制阴影、4 个阅读主题（米白 / 护眼绿 / 羊皮纸 / 夜间）。基础令牌精确值与间距 / 圆角 / 动效沿用逆向对齐版，未改动。
- **为合规主动舍弃的番茄小说机制**：本稿**不实现**「排行榜 / 推荐流 / 自动轮播 / 福利橙红落地页 / 搜索框 / 书架」等增长型或超范围机制；书城只用「合规横幅 + 多维筛选器 + 卡片网格」发现作品。
- **响应式**：≥768px 顶部导航（5 工作空间 + 视图子导航）；≤767px 工作空间切换收为**底部标签导航**（`env(safe-area-inset-bottom)` 安全区），页脚转纵排。
- **阅读器 R03**：≥1024px 工具栏为右侧常驻竖排第三列（sticky）；<1024px 为中央唤出式底部工具栏 + 中央「Aa」唤出按钮；两种形态同一 DOM 同一 JS 状态。
- **数据基准**：固定演示基准日期（2026-11-12），所有「X 小时前」「更新时间」由确定性派生，不读系统时间、不出现未来时间。

## 五、如何逐态核对

1. 顶部 5 项「书城 / 创作工作区 / 审核工作区 / 运营与配置 / 我的」为 **demo 工作空间切换**，界面明确标注「不是登录态、不产生业务数据」。切换后子导航只显示该工作空间的视图；窄屏在页面底部提供同一组切换（底部标签，共 5 项 10 个按钮实例）。
2. 子导航首个入口 `V0 令牌与四态速览` 始终可达；其余视图均可通过导航到达（含 R01 → R02 → R03 阅读主路径）。
3. 每个视图右上角固定位置均有「**状态演示（评审用）**」控件，四个按钮分别切换**加载 / 空 / 错误 / 成功**。它只切换该视图的展示态，不产生业务数据、不写入本地存储。
4. 错误态的「重试」按钮是演示态切换（加载态 → 成功态），无网络请求。
5. V0 提供全量「四态 × 场景核对表」，请据此到各视图逐格复现。
6. 弹层支持焦点进入、Tab 封闭、Escape 退出、关闭后焦点恢复；键盘切章 tooltip 支持 Esc 关闭。

## 十、实现取舍与已知字面对照（供 Owner 裁决）
