## 2. 定位、用户与目标

消费级 UGC 长内容阅读社区，服务读者、业余作者及平台治理人员。业务目标是用户留存与内容健康；首期交付安全的阅读、创作、审核、申诉闭环，不以收入和页面数量验收。

### 2.1 指标口径

| 指标 | 计算 | 窗口与采集 | 验收用途 |
| --- | --- | --- | --- |
| 次周回访率 | 首周有效阅读用户中次周再次有效阅读人数/首周有效阅读人数 | 自然周，Asia/Shanghai；有效阅读为前台累计60秒且达到章节10% | 上线后连续4周建立基线；本轮不虚构提升比例 |
| 章节完读率 | 达到90%阅读位置的去重用户章节对/打开过章节的去重用户章节对 | 日统计，匿名聚合；前台阅读≥60秒 | 衡量阅读体验，不采集正文和敏感身份到分析系统 |
| 发布一次成功率 | 首次提交后无需作者修订即发布的版本/首次提交的版本 | 自然周，技术失败和审核退回分别分桶 | 不得将降低审核尺度作为提高成功率手段 |
| 内容健康 | 确认误放件数、P0事件数、审核SLA达标率分别报告 | 日统计，风险/年龄分层 | 任一已知P0漏放未处理即禁止上线 |
| 追更转化率 | 新建追更关系人数/作品详情访问人数 | P1启用后按周 | P0仅定义事件，不报告产品效果 |

## 3. 范围与角色

### 3.1 P0、P1、P2边界

| 阶段 | 本阶段交付 | 不交付 |
| --- | --- | --- |
| P0 | 四端最小闭环；跨Web/iOS/Android共享契约；身份年龄保护；不可变版本；机审与人审；下架申诉；治理配置审批；结果通知；审计；B0付费骨架；可观察与安全基线 | 真实支付、积分、礼物、奖励、私信、离线/PWA、个性化推荐 |
| P1 | 收藏/追更完整交互与聚合通知、元数据搜索、规则召回、数据看板、治理增强 | 不自动启用任何交易或激励 |
| P2/B | 多角色协作、实验平台、社交、多形态内容、开放平台、商业化专项 | 未单独立项不进入实施 |

P0正文版本存储、全入口可见性、限流与灾备设计是安全发布的依赖，不因历史O24/O25/O28排在P2而缺省。P1专属搜索和推荐未上线时，P0只验收实际存在的入口，并明确扩展契约。

### 3.2 年龄与内容访问

年龄按境内公历周岁计算；边界为14、16、18岁生日当天。2月29日出生者在非闰年按3月1日变更年龄。升级须实名复核；风险纠正降级立即生效。该生日边界为工程候选，法务冻结前不得开放年龄升级。

| 层级 | 范围 | 可阅读 | 公开发布 |
| --- | --- | --- | --- |
| C0 | <14 | G、PG_12 | 禁止；仅私有草稿；注册须监护人同意 |
| C1 | ≥14且<16 | G、PG_12 | 禁止；仅私有草稿 |
| C2 | ≥16且<18 | G、PG_12、PG_16 | 已核验年龄+有效监护同意+作者资质；每件必人审 |
| C3 | ≥18且实名复核通过 | G、PG_12、PG_16；A须额外入口确认 | 作者资质有效且角色不冲突 |
| C4 | 年龄未核实 | 按C1 | 禁止；自报成年不能升级 |

A等级在P0默认关闭；不进入发现列表。年龄声明比已核验记录更严格时按更严格结果限制并触发复核。审核员只接收年龄层和核验状态，不接收证件、完整生日。

### 3.3 角色与授权

| 角色码 | P0能力 | 禁止项 |
| --- | --- | --- |
| READER | 阅读、阅读进度、本人通知、举报、本人申诉 | 草稿、后台、其他人的进度 |
| AUTHOR | 本人作品、草稿、提交、版本、申诉 | 审核、编辑已发布正文 |
| GUARDIAN | 已核验关系的同意与撤回 | 代写、裁决他人内容 |
| REVIEWER_L1 | 分配队列阅读、人工裁决、升级 | 兼任作者、运营，改稿、原审复核 |
| REVIEWER_L2 | 高风险双审、非本人原审申诉复核 | 自批、越队列、修改原裁决 |
| OPERATOR | 分类与配置提案、内容治理申请 | 修改审核结论、正文与审计 |
| ADMIN | 账号角色管理、配置审批 | 内容裁决、代笔、审计删除、申请自批 |
| AUDITOR | 授权范围脱敏审计查询 | 任何业务写入 |
| LEGAL | 法律案件复核、合同终止提案及独立复核 | 自批、原审申诉复核、越作用域读取、修改原始证据 |
| SYSTEM | 按服务身份执行确定系统动作 | 模拟人类审核员、扩大到通用管理员权限 |

账号维度禁止审核角色与AUTHOR/OPERATOR共存；对象维度禁止申请人与审批人同一身份，禁止原审人参与申诉复核。只切换角色上下文不能绕过互斥。财务权限仅建模，P0不授予交易执行权。

## 5. 非功能与安全验收口径

| 项 | P0要求 |
| --- | --- |
| 规模基线 | MAU<10万、DAU约1万、作品5万、章节200万、峰值读并发3000；额外5倍峰值余量为15000并发压力档 |
| 可用性 | 99.95%，按月有效请求成功率；容量压测不证明月度可用性 |
| 时延 | 首屏P95<1000ms；读接口P95<300ms；发布与审核异步返回202，不把机审时延藏入阅读指标 |
| 下架 | 从治理阻断提交成功到所有现有入口拒绝≤60秒；新请求被拒绝，已下载内容不能远程抹除 |
| 灾备 | Tier0审计/实名/合规多AZ同步副本RPO≈0；Tier1 RPO≤15分钟/RTO≤4小时；缓存可重建 |
| 内容防泄漏 | 对象存储不公开；正文不可通过已过期链接和源站绕过闸门；人审禁止批量导出 |
| 质量 | 核心行≥90%/分支≥85%；一般服务80%/70%；前端行≥70%；P0旅程100%自动化 |
| 输入 | JSON白名单、长度/大小限制、纯文本正文、图片仅受控资源引用；禁止客户端设置角色与风险结论 |
| 数据 | 全部低环境仅合成数据；正文不得进入普通日志，个人/合规数据字段分级 |
