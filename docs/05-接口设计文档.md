# 接口设计文档

## 1. 契约身份

P0-BL-1，2026-11-12。机器契约为[OpenAPI](../contracts/p0.openapi.yaml)，REST使用OpenAPI3.0.3。本文负责授权、事务与行为；字段、类型、必填与枚举以机器契约为准。接口尚未实现，不把schema校验称为接口联调通过。

## 2. 全局协议

| 项 | 规定 |
| --- | --- |
| 路径 | 客户端/api/v1；Agent专用/internal/v1，不公开路由到用户网关 |
| 身份 | OIDC Bearer，固定issuer/audience白名单、签名和到期校验；用户/Agent使用不同audience与权限 |
| 主体 | userId来自令牌subject映射，不接受X-User-Id、角色请求头或请求体自报权限 |
| 请求 | API控制请求为application/json；未知字段拒绝；≤512KiB；纯文本正文≤100000字符且UTF-8≤400KiB。私有图片仅按上传授权单键PUT二进制，JPEG/PNG且≤5242880字节，不经JSON正文 |
| 响应 | JSON信封code、message、data、traceId全部必填；成功code=OK；错误data=null；信封及具体data拒绝未知字段。GET /assets/{id}/content成功为受控图片binary，错误仍用JSON信封；不暴露堆栈 |
| 写幂等 | 所有POST/PUT/PATCH要求Idempotency-Key UUID；同主体/方法/路径24h去重；不同载荷409/B2003 |
| 版本 | 可变资源写入要求If-Match，格式为带引号的正整数ETag；GET响应ETag。缺失428、过期412 |
| 游标 | 默认limit20、上限100；cursor最长512字符，绑定主体/筛选器、15分钟过期；失效400/P1001 |
| 时间与标识 | UTC date-time；UUID；金额分整数；排序固定加id稳定键 |
| 缓存 | 私有/后台/身份响应Cache-Control:no-store；公开内容缓存仍须每次鉴权与下架闸门，不暴露源站URL |
| 调用限制 | 详08；429携带Retry-After秒数；客户端停止自动写重试并保留原幂等键 |
| 协议安全 | TLS；Web令牌仅内存，PKCE、刷新会话由安全HTTP-only同源边界管理；原生Keychain/Keystore；CORS明确域白名单，不使用任意来源 |

本期所有公开浏览也经过统一闸门；未登录访客按C4，以无Bearer调用公开目录/阅读API。登录令牌无效时返回401而不是降成游客绕过账号限制。

所有列表先按主体、作品归属、案件/队列或规则域授权过滤，再执行limit/cursor分页，不返回隐藏总数。详情ID来自授权列表或创建回执，不得要求客户端猜ID；持有ID本身不授予权限，详情继续校验，越权与不存在统一404。可变资源详情返回ETag，读取资格与审批资格分离。

## 4. 字段与行为补充

### 4.1 草稿载荷

WORK载荷包含workId/title/synopsis/categoryId/tags，chapterId与body禁止；CHAPTER载荷包含workId/chapterId/title/body，synopsis/categoryId禁止。字符串先归一化换行并保留正文空白，不对文学正文做破坏性“去重”。保存必须非空标题，提交再验证完整性。工作草稿提交时审核包括标题、简介、分类、标签、封面资源；无封面时使用系统纯排版占位，不自动生成外部素材。

### 4.2 提案审批

ReviewRequest只允许APPROVE/REJECT，附reason与evidenceRefs；操作者来自身份上下文。审批时If-Match必须匹配提案，批后不得替换payload；需要修订则新建提案。高权角色授予/治理申请均记录经办与复核身份。

监护同意、角色授予、限制、申诉、权利请求及配置提案视图均包含createdBy/createdAt、原始请求（配置沿用change，其他为request）、revision、状态及完整reviews。原始请求不可覆盖；ReviewRecord保留actorId、action、reason、evidenceRefs、reviewedRevision和createdAt，尚未审查时为空数组，不得截断审批历史（单提案最多100条，超限须新提案并保留旧记录）。审批/处理身份由服务端认证上下文写入；监护核验由受信核验服务回查，撤销仅同意监护人；权利处理仅授权隐私处理服务，本人查询不等于自行批准。申诉caseId、权利kind等视图索引字段须与原始请求一致。

RoleGrantRequest以oneOf强制GLOBAL禁止scopeId；WORK/QUEUE/CATEGORY必须有scopeId，并核验目标真实存在及授权范围。RestrictionRequest以oneOf强制TEMPORARY必填expiresAt（服务端要求未来到期），FINAL_VIOLATION/CONTRACT_TERMINATED禁止expiresAt，不能伪装自动到期恢复传播。

分类变更只走现有config-revisions创建→独立审批→定时激活管线，无独立分类创建写入口。CONTENT_CATALOG与REVIEW_ROUTING/ACCESS_POLICY/NOTIFICATION_POLICY组成PolicyPayload.oneOf；categories为1至1000项完整有界快照，每项必含id/name/parentId/enabled/sortOrder，含停用项而非增量补丁。服务端在提案及激活时校验ID唯一、树无环、父引用完整、历史引用完整；使用中（含草稿与历史版本）分类不可删除，只能启停且不丢历史。激活在同一事务内应用catalog快照并更新配置状态；分类配置rolloutBasisPoints固定10000，不能部分灰度。回滚同样走新提案并重新检查引用，不覆盖审批快照。

baseRevision必填，等于创建时同key全部ACTIVE版本的最大revision，无ACTIVE为0；审批与激活重新核对，过期返回412，不能覆盖期间激活的新配置。rolloutBasisPoints为1至10000，ACCESS_POLICY同CONTENT_CATALOG固定10000；其余类型按03全量/灰度双槽和稳定分桶规则应用，不改写已批准比例。

### 4.3 机审报告

报告只包含结构化风险/建议/置信度及内部证据引用。riskFlags完整集合MINOR/ILLEGAL/MONEY_DISPUTE/PRIVACY/COPYRIGHT；LOW也不得覆盖必人审标记。服务核验versionId/workflowId/caseId、policyVersion、materialSha256全部一致；materialSha256绑定不可变完整审核材料快照，不是仅正文哈希。原有modelVersion、risk、riskFlags、suggestedDecision、confidence、evidenceRefs、inputTokens、outputTokens、durationMs等字段全部保留。输入token与输出token非负，confidence∈[0,1]。unknown字段直接400；鉴权或范围错403；旧流程已取消返回409并记录过期事件。

MachineReport.suggestedDecision与DecisionRequest.decision均以oneOf约束：PASS/LABEL/LIMIT必填grade（G/PG_12/PG_16/A），REVISE/HIDE/REMOVE/BAN/ESCALATE禁止携带grade（也不能传null）。DecisionView保留grade、reasonCode、evidenceRefs以及原有身份/决定/理由/时间，使用相同grade条件，供独立二审完整比对，不以机审建议替代人工结论。

### 4.4 结果信封

同步变更通常返回200+Receipt，字段id、resourceType、state、revision；草稿提交返回202+SubmissionReceipt，字段workflowId、versionId、state；上传授权创建返回200+AssetUploadGrant。GET按资源返回具体模型，素材内容成功响应为binary而非JSON。所有“成功”仅指本次请求语义，202不得解释为审核通过。机器契约中Receipt的state是各资源允许状态并集，补入PROCESSING/HELD/EXPIRED/SUPERSEDED及AWAITING_UPLOAD/CHECKING/COMPLETE，resourceType补ASSET_UPLOAD；operationId对应合法子集仍须与03状态机同步。上传完成回执id是会话ID，正式assetId通过状态查询取得。

SuccessBase在同一层声明code/message/data/traceId并拒绝未知信封字段，各具体Response再用allOf将data收紧到严格模型；不能在未声明data的基类上关闭额外字段而误拒绝全部成功响应，也不能直接用未收紧的SuccessBase作为响应。除B0账务保留骨架外，新增模型均由实际端点响应或请求链引用。

### 4.5 上传与素材安全边界

AssetUploadRequest仅允许purpose=COVER/EVIDENCE，contentType=image/jpeg或image/png，sizeBytes为1至5242880，sha256为原始字节的小写64位十六进制SHA-256；不接受文件URL或客户端BODY上传。COVER必须有workId且禁止caseId，校验本人AUTHOR与作品归属；EVIDENCE必须有caseId且禁止workId，校验已登录案件参与关系并预绑定该案件，不能拿任意案件ID借权。

授权仅300秒（expiresAt=createdAt+300秒），固定唯一隔离对象键和PUT方法；客户端原样发送requiredHeaders中的Content-Type，与请求contentType必须一致。签名无列桶/读取/其他键写入权限；大小与SHA-256绑定会话并以服务端实际字节复核。幂等重放不得延长签名，过期新建会话；客户端不得自选键、改绑作品或案件。uploadUrl仅运行时上传能力，不是公开素材或内容下载地址，日志须脱敏。

完成请求要求Idempotency-Key和If-Match及空对象；服务端重新校验主体归属，冻结隔离对象版本，复验大小/hash、MIME魔数、图片解码及恶意内容安全检查。状态AWAITING_UPLOAD→CHECKING→COMPLETE；失败REJECTED，未完成上传的过期会话EXPIRED；存储不可用时阻断并保留可观察检查状态。只有安全检查通过、EVIDENCE最终绑定原案件（COVER绑定原作品）后，才原子生成正式assetId并置COMPLETE；其他状态assetId必须为null。已完成正式对象不可被尚未过期的旧PUT签名覆盖；只有本作品COMPLETE且安全检查通过的COVER可用于coverAssetId，EVIDENCE正式资源引用必须与提交证据的案件一致，不能把上传会话ID当资源引用。

素材读取仅允许对应作品/案件作者本人，或当前对关联案件具有有效阅卷资格/租约的阅卷人。EVIDENCE上传参与资格不自动授予内容下载资格；每次读取重新检查绑定、完成状态及当前权限，撤权立即阻断。成功返回实际匹配的image/jpeg或image/png二进制及Cache-Control:no-store、X-Content-Type-Options:nosniff；失败仍为no-store的统一JSON错误，不重定向、不暴露源站或签名下载地址。此私有接口不替代未来公开封面分发，也不为正文提供上传旁路。
