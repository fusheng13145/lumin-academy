### 1.2 关键功能模块

**读者侧**
1. 全局：顶部导航（首页/书库/书架/原创榜/作家专区/版权专区）+ 胶囊搜索框（「请输入书名或作者名」）+ 登录/注册；右侧常驻悬浮快捷栏（番茄小说/帮助中心/作家助手）；首页轮播（4 帧，含运营向 banner）。
2. 首页内容矩阵：作家福利三栏导流 → 番茄巅峰榜 Top18（排名+书名+分类+封面）→ 最新资讯 8 条（公告/征文/处罚公示）→ 殿堂/金番作家墙 55 人 → 男频/女频精选各 6 本 → 分类榜（20+ 分类 × 阅读榜/新书榜 Top10，标注「仅展示原创作品，统计时间截止至 MM-DD 24:00」）→ 版权出版书目（书名/作者/出版社/签约日期）→ 最近更新表（类型/书名/最新章节/作者/更新时间，11 行）→ 页脚。
3. 书库筛选器：**读者（全部/男生/女生）× 分类（全部/主题/角色/情节）× 状态（全部/已完结/连载中）× 字数（全部/30万以下/30–50万/50–100万/100–200万/200万以上）× 排序（最热/最新/字数）**；书卡字段 = 封面/书名/作者/状态/字数/简介（~100 字）/更新时间（相对时间「22小时前」或绝对时间）；分页器 99 页。
4. 书详情页：面包屑（首页/书名）→ 书头（封面+状态徽章「已完结」+主分类+标签组+字数「41.1万字」）→ 最近更新章节链接+时间 → CTA（开始阅读/下载APP）→ 作者卡（头像/名/签名）→ 作品简介 → **全量章节目录（卷分组 + 逐章链接 + VIP 标记）** → 页脚。
5. 阅读页：H1 书名 + H1 章节名 + 章节元信息（**本章字数：2047 字；更新时间：11分钟前**）+ 段落正文 → 未登录付费墙（扫码/登录引导 + 开发者信息/版本号）→ 底部上一章/下一章按钮 → **右侧常驻工具栏：加书架/目录/夜间/字号（+下载/领红包）** → 键盘左右键切章（tooltip 提示「试试使用键盘左右键切章吧！」）。
6. 存储：IndexedDB `bookRecordDatabase`（阅读记录）+ `bookItemsRecordTable`（书架）；localStorage 含字节系埋点（`__tea_*_2503`）、监控（`SLARDARnovel_pc`）、安全 SDK 缓存。

**作家侧**
7. 独立作家子站：福利 banner（全年/半年/季度奖、优质加更奖、新书追更奖）→ 登录引导卡 → 公告流（创作计划/征文/处罚公示，带日期）→ **作家课堂**（新手专区/品类指南/写作技巧/大神专访，10 篇教程逐篇标注适用对象）→ 版权出版书目 → 作家寄语墙 → 版本公告。
8. 作家工作台（`/main/writer/author`，登录墙）未检视。

### 1.3 页面结构与视觉特征（首页截图 `docs/11-assets/rea_home.png`）

- **配色**：整页白底 + 深黑标题 + 中灰辅助文字；番茄红**仅用于 logo 图标与极少量点缀**；英雄区为浅蓝插画横幅（氛围位）；无大面积红底。
- 顶部导航白底、当前项深色加粗；搜索框浅灰胶囊、圆角全圆、右置放大镜；登录/注册为纯文本链接。
- 卡片圆角适中、留白宽松、扁平无重阴影；书封统一 3:4 带 3D 书脊质感。
- 榜单条目：灰色序号 + 书名 + 分类灰字 + 右侧封面，横向分组呈现。

### 1.4 交互流程（实测）

1. **阅读主流程**：书库筛选 → 书卡 → 书详情（简介+目录选章）→ 阅读页（元信息+正文）→ 底部按钮或键盘 ←/→ 切章；右侧工具栏随时切夜间/字号/目录。
2. **阅读主题**：根元素 `muye-data-theme` 属性驱动（与我方 `data-read-theme` 同构）。
3. **筛选**：多维筛选为整行 chip 组，选中后列表刷新 + 分页重置。
4. **未登录边界**：正文展示部分段落后截断，给出「会员登录后可在网页畅读全文」+ 下载引导——**用状态提示划清权限边界**（这一机制可合规借鉴，付费墙本身弃用）。

### 1.5 数据接口与存储迹象（受限证据，如实呈现）

| 迹象 | 证据 | 推断 |
| --- | --- | --- |
| 阅读记录/书架本地化 | IndexedDB `bookRecordDatabase`、`bookItemsRecordTable` | 阅读进度与书架有本地持久层（离线兜底） |
| 主题由服务端/客户端统一管理 | `<html lang="zh-CN" muye-data-theme="...">` | 主题是**页面级状态**，SSR 即注入 |
| 埋点/监控/安全 | `__tea_cache_*_2503`、`SLARDARnovel_pc`、`web_security_runtime_cache_*`、`xmst` | 字节系标准基建（埋点上报、Slardar 监控、secsdk 风控） |
| SEO 模板 | title「{书名}完整版在线免费阅读_{书名}小说_番茄小说官网」 | 书详情/阅读页 SSR + 关键词模板 |
| **接口契约** | 无（政策过滤） | 无法获取 API 路径/响应形状，接口对比**不在本轮证据范围内** |
