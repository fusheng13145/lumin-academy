## 1. 项目定位、目标、北极星指标与本期范围边界

### 1.1 定位与目标

| 项 | 结论 | 出处 |
| --- | --- | --- |
| 项目定位 | 消费级 UGC 长内容阅读社区；读者消费 + 作者创作，平台居中做分发与治理 | 设计方案 1.1 A；项目基线 §1.1；01 §2 |
| 用户与端 | 读者（全年龄含未成年）、业余 UGC 作者、审核、运营四类业务界面；**Web + 原生 iOS/Android 并行**（非 Web 优先）；四端指四类业务界面，不是四个操作系统 | 设计方案 1.1 A/C、3.6.5；01 DEC-01；06 §2 |
| 系统现状 | 全新从零建设（greenfield），无存量数据迁移，O27 降为「预留不启用」 | 设计方案 1.1 E、3.6.11；设计方案 3.2.2 |
| 业务目标 | 首期交付**安全的阅读、创作、审核、申诉闭环**，不以收入和页面数量验收；变现后置 | 设计方案 1.1 A；01 §2 |
| 北极星指标 | **用户留存与内容健康**（变现后置） | 设计方案 1.1 A；01 §2 |
| 交付治理 | 业务方为**唯一需求 Owner**；变更走评审 + 版本化，影响 P0 范围须重走验收矩阵；法务/合规/安全为强制校验 checkpoint（否决/风险提示权，无决策权） | 设计方案 1.2 6.14、3.6.14；01 §1 |
