# 全量测试（3499 + 3 + 3；增量三十六另加 3 个身份集成用例，真实 MySQL 集成测试需要 LUMIN_TEST_DB_PASSWORD，未配置时按 Assumption 跳过）

## 6. 常见坑（教训登记，按出现频率排序）

1. **`-pl lumin-bootstrap` 运行须先 `mvn install -DskipTests`**：否则兄弟模块
   （lumin-application 等）从本地仓库解析旧 jar → 运行时 `NoSuchMethodError`。
   带 `-am` 的命令从源码构建不受影响。
2. **Windows 下重定向日志为宽字节/混合编码**：grep 无输出时用 `grep -a`。
3. **`mvn … > /dev/null 2>&1` 吞掉 BUILD FAILURE**：对着陈旧 surefire 报告推理
   不存在的现象——排查前先确认编译确实通过。
4. **surefire XML/stdout 可能缺失中途调试打印**：把「哪一步没发生」变成数据断言
   （DB 行状态/outbox 投递状态），不要依赖 stdout。
5. **依赖机审 AUTO 链的集成测试必须钉两个开关**：`lumin.review.calibration-valid=true`
   + NeverSampledGate 抽检闸（5% HMAC 命中会路由人工 → 发布链非确定）。
6. **`SELECT *` mapper 的 record 字段顺序必须与表列序完全一致**（按列序对位映射）。
7. **dev 库 `lumin` 与测试库 `lumin_test` 分离**：新迁移需手工补 DDL 到 dev 库。
