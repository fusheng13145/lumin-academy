## 2. 令牌映射表（CSS 变量 → 06 §1.1 精确值 → 使用位置）

```css
:root {
  /* 色彩 · 06 §1.1 */
  --surface:          #F5F8FA;  /* 冷白阅读背景，不使用奶油纸张模板 */
  --paper:            #FFFFFF;  /* 正文与表单表面 */
  --ink:              #172D3E;  /* 主文字 */
  --secondary:        #4E6575;  /* 辅助说明，不用低对比浅灰正文 */
  --accent:           #245C75;  /* 主要操作、焦点、章节位置 */
  --danger:           #9C303B;  /* 风险与不可恢复操作；不能只靠颜色传达 */
  --border:           #C2CFD8;  /* 非交互分隔；交互边界使用 secondary */
  --night-surface:    #13202A;  /* 夜间阅读背景 */
  --night-ink:        #E6EDF2;  /* 夜间主文字 */
  /* 间距 · 06 §1.1 */
  --space-1: 4px;  --space-2: 8px;   --space-3: 12px; --space-4: 16px;
  --space-5: 24px; --space-6: 32px; --space-7: 48px;
  /* 圆角 · 06 §1.1：控件 6px、弹层 8px；不用大圆角堆叠卡片模拟内容 */
  --radius-control: 6px;  --radius-overlay: 8px;
  /* 字体栈 · 06 §1.1：P0 不从境外 CDN 拉字体 */
  --font-title: "Songti SC", "Noto Serif CJK SC", serif;
  --font-read:  "Songti SC", "Noto Serif CJK SC", serif; /* 用户可切换系统无衬线 */
  --font-ui:    "PingFang SC", "Microsoft YaHei", sans-serif;
  --font-mono:  ui-monospace, SFMono-Regular, Menlo, Consolas, monospace;
  /* 字号 · 06 §1.1 */
  --title-1: 28px; --title-2: 24px; --title-3: 20px;
  --ui-body: 16px; --ui-aux: 14px;
  /* 阅读参数 · 06 §1.1（独立可调，仅体验层） */
  --reader-size: 20px;      /* 可调 16–32px */
  --reader-leading: 1.8;    /* 可调 1.5–2.2 */
  --reader-measure: 44em;   /* 可调 32–44em */
  /* 动效 · 06 §1.2 */
  --panel-motion: 120ms;
}
[data-theme="night"] {
  --surface: var(--night-surface);
  --paper:    var(--night-surface);
  --ink:      var(--night-ink);
  --border:   #2C3E4A;
  --focus-color: var(--night-ink);            /* 06 §1.1：夜间焦点用 nightInk */
}
:root { --focus-color: var(--accent); }
*:focus-visible {
  outline: 3px solid var(--focus-color);       /* 06 §1.1：3px accent 实线 */
  outline-offset: 2px;                        /* 外偏移 2px；不移除键盘焦点 */
}
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after { animation-duration: 0ms; transition-duration: 0ms; }
}
```

## 3. 辨识元素：章节边注轨道（V2 阅读器）

> 设计方向「阅读目录与书页边注」；辨识元素是**章节边注轨道：只表达当前位置、版本变更和审核批注，不作无意义装饰编号**（06 §1）。

| 项 | 规格 | 出处 |
| --- | --- | --- |
| 允许的三类标记 | ① **当前位置**：「你在此 · 第 7 章」；② **版本变更**：「本章已修订 · v2」；③ **审核批注**：「内容等级 G · 已标注」。除此之外不得出现任何标记 | 06 §1；09 §6.2 |
| 明确禁止 | ①②③ / № 等装饰性编号；与内容无关的序号；评分、热度、广告位；把边注当重复章节目录；把边注做成装饰性竖线阵列 | 06 §1、§1.2；09 §6.5 F-01/F-03 |
| 桌面 ≥1280px | 轨道绝对定位于**主栏右侧留白**（宽度 176px），与对应段落按锚点对齐；主栏仍不超过 44em；**不新增第五个导航列**，右侧只保留必要排版开关 | 06 §3.1 |
| 1024–1279px / 768–1023px | 轨道折叠为**段末行内标记条**（细左边框 + 文本），不占独立列；平板目录为可关闭抽屉 | 06 §3.1 |
| <768px | 折叠为段末行内标记条，单栏正文；不出现横向溢出 | 06 §3.1、§5 |
| 视觉 | 当前位置：3px `--accent` 竖线 + `--accent` 文本；版本变更与审核批注：`1px --border` 分隔 + `--secondary` 文本；标记条高度随文本，最小触控目标 44×44px（可点击的「本章已修订」） | 06 §1.1、§3.1 |
| 与版本交互 | 点击「本章已修订 · v2」→ 弹出「本章已修订」确认（说明版本变化），用户确认后**从章首定位**，不把旧百分比强行写进新版本；确认框用明确文本，不用通用「确定吗」 | 06 §3.1、§3.4；09 §6.5 F-05 |
