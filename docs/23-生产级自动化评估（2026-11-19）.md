### 3.1 代码质量

- 主源码 327 个 Java 文件、约 17,025 行；最大类 `WorkService.java` 395 行，其次 `ReviewCaseService.java` 340 行、`AiWorkflowService.java` 296 行。

- 878 个 Javadoc 块；308/327 文件至少一个类级注释。无注释的 20 个类均为简单 DTO/Row/Mapper/启动类，或 AI 视图对象。

- 五模块：`lumin-domain`、`lumin-application`、`lumin-infrastructure`、`lumin-ai`、`lumin-bootstrap`。
- 允许方向：`bootstrap -> {domain, application, infrastructure, ai}`；`infrastructure -> {application, ai}`；`ai -> {domain, application}`；`application -> domain`；`domain` 零框架依赖。
- 326 个源文件被依赖脚本扫描，15 条允许跨模块边，0 非法边、0 环；`application` 未直接 import `infrastructure`/`bootstrap`。

### 3.3 错误处理

- `GlobalExceptionHandler` 覆盖 `LuminBusinessException`、请求体/参数/头缺失、`NoResourceFoundException` 和兜底 `Exception`。
- 兜底错误码 `D2001`（HTTP 503），只记录 traceId/异常日志，不向客户端回显原始异常；`D2002` 同为 503。
- `ErrorCodes` 共 14 条（OK + 13）；业务码、参数码、鉴权码、依赖码分层清晰。
- `NotificationService`、`ReviewResolvedConsumer`、`PublicationSubmissionConsumer` 对 `DuplicateKeyException` 做幂等处理。
- 新增 `GlobalExceptionHandlerTest` 2 用例：`B2004 -> 404 + 信封`、`D2001 -> 503` 且响应不含 `"secret-detail"`。
- 新增异常路径测试覆盖：草稿状态冻结/乐观锁冲突、素材上传签名篡改/大小/摘要/魔数、发布撤回 `If-Match`、角色自审拒绝与角色互斥、监护同意重复凭据/越权/撤销。
